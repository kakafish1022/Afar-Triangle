🦁 幾何密碼：大草原獅王之路（Afar-Triangle）

貳餘 · 幾何系列（全 100 關）

結合「畢氏定理」與「最簡根式化簡」的空間解謎遊戲。引導小獅穿越草原網格、避開障礙，讓移動總距離吻合石碑上的根式密碼！

🎮 版本說明

手機 4×4 經典版（第 1～50 關）：單手滑動連線，適合手機隨時遊玩。

獅王遠征篇（第 51～100 關，電腦／平板限定）：棋盤從 5×5 一路擴展到 7×7，挑戰高階根式組合。

📖 玩法與規則

距離計算：相鄰格點間距為 1，每一步距離依畢氏定理自動化為最簡根式並累加。

路線限制：不可經過巨石（🪨）與湖泊（💧），且同一關不可重複踩點。

宗師提示：卡關時可開啟提示顯示「第一步落點」，使用提示通關最高獲得 1 星（重走本關可無提示衝刺三星）。
